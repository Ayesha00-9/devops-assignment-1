# Weather Advice Generator

## Description

This is a simple Python application that provides weather advice based on the temperature entered by the user.

## Features

- Accepts temperature in Celsius.
- Provides weather-related recommendations.
- Handles invalid input.
- Uses functions and conditional statements.

## How to Run

```bash
python app.py
```

## Example

```
========================================
      Weather Advice Generator
========================================
Enter temperature (°C): 38

Weather Report
----------------------------------------
Temperature : 38.0°C
Advice:
- Stay hydrated.
- Wear light clothes.
- Avoid direct sunlight.
```
